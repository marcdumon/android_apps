# Tasks (Android web app)

A full-screen WebView on <https://tasks.google.com/>. Nothing else: no offline, no notifications.

Generated by ../webapp_generator/new_webapp.sh. Do not edit the Java here - edit
webapp_generator/webapp_template and regenerate, or the next regeneration overwrites it:

    ../webapp_generator/new_webapp.sh --name 'Tasks' --url 'https://tasks.google.com/' --dir webapp_google_tasks --id com.md.gtasks --ua desktop --force

Build:   ./build.sh   ->  ./tasks.apk
Install: copy the APK to the phone and tap it, or
         ~/Android/sdk/platform-tools/adb install ./tasks.apk

The user agent claims to be desktop Chrome. That is deliberate: the "wv" token in a stock WebView
user agent makes Google refuse to sign you in, and a mobile token makes sites serve their phone
layout. See buildUserAgent() in the template.

KEEP gtasks.keystore. Without it a rebuilt APK can no longer install over the copy on the phone.
